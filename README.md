# Chuma Ejekute-Obi | Cybersecurity

## What I Work On

- Analyze suspicious files using hashes, VirusTotal intelligence, and process-monitoring workflows.
- Test web applications in authorized environments using request inspection, endpoint mapping, input testing, and session-security review.
- Examine network traffic, DNS activity, ports, and process behavior to identify indicators that require investigation.
- Build security-focused Python and PowerShell tools for repeatable scanning, monitoring, and lab automation.
- Research firmware and embedded systems through chip identification, binary extraction, and static analysis.
- Document findings with clear evidence, realistic risk statements, and practical mitigation recommendations.
